# BLP Access Control Visualizer

ITIS 3200 — Lab 5

Python simulation of the Bell-LaPadula confidentiality model, demonstrating no read up, no write down, and 18 access-control scenarios.

## Files

- `BLP.py` — BLP access control implementation.
- `Cases.py` — 18 scenarios and command-line runner.

## Run

From this folder:

```bash
python Cases.py
```

Select `A` to run all cases or enter a number from 1 to 18 for an individual case.
